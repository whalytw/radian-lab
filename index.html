1. 弧度的意義

θ = s / r
s = rθ
s = 5
當 θ=1 弳時，弧長剛好等於半徑。
1 弳的核心：弧長 = 半徑。半徑不管變大或變小，只要弧長跟半徑一樣長，圓心角就是 1 弳。

2. 度與弳的換算

180° = π 弳
60° = π/3 弳
約 1.0472 弳
度轉弳：乘上 π/180；弳轉度：乘上 180/π。

常見角快速對照

度60°
弳π/3
小數弳1.0472

3. 同界角

相差 2π 的整數倍
60° → 780°
π/3 → 13π/3
兩角相差 720° = 4π，所以同界。
同界角不是「角度一樣」，而是轉完之後的終邊位置一樣。

4. 扇形的弧長與面積

s=rθ，A=½r²θ
弧長 s4π
面積 A20π
角度72°
這兩個公式的 θ 必須是弳。如果題目給的是度，要先換算。

6. 摩天輪應用

轉過的弳、走過的弧長、離地高度一起看

設定為「從最低點出發、逆時針轉」。轉過角度 θ = 2π ×（時間 / 一圈時間）。
